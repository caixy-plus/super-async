Server 本地模式

单机高吞吐

调度器与执行器同进程运行，消除网络开销，适合对延迟极度敏感的单机场景。

  • 调度器与执行器同进程
  • 零网络延迟
  • 单机最高吞吐
  • 内存级任务传递
Worker 远程模式

水平可扩展

调度器通过 HTTP 向独立 Worker 分发任务，支持动态扩缩容，适合大规模分布式场景。

  • HTTP 任务分发
  • Worker 动态扩缩容
  • 多节点负载均衡
  • 故障自动转移

核心特性

面向生产环境的企业级能力

高吞吐调度

优化的调度引擎，支持每秒万级任务分发，满足高并发业务需求。

低延迟执行

毫秒级任务响应，本地模式消除网络开销，远程模式优化传输协议。

水平扩展

支持集群部署，随业务增长弹性扩容，Worker 节点动态上下线。

任务监控

完整的任务状态追踪、执行日志和实时监控面板，任务状态一目了然。

容错机制

自动重试、死信队列、任务超时处理，保障任务最终完成。

SDK 接入

提供 Java SDK，极简 API 调用，几行代码即可接入任务调度平台。
